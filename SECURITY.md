# Security Policy

## Supported versions

This repository powers the Pull landing page (UMKM Solo Raya). Only the latest production deployment is maintained — older deployments and forks are out of scope.

## Reporting a vulnerability

Please report suspected security issues **privately** — do not open a public issue:

- **Email:** [halo@pull.id](mailto:halo@pull.id) — subject `[SECURITY] <short summary>`
- **GitHub:** open a [private vulnerability report](https://github.com/stoy109/Pull-LandingPage/security/advisories/new) (Security tab → *Report a vulnerability*)

You can expect an acknowledgement within **3 working days**. A useful report includes:

- a description of the issue and its impact,
- reproduction steps or a proof of concept,
- the affected URL/commit, if known.

Valid reports will be credited in the release notes unless you prefer to stay anonymous.

## Scope

**In scope:** this website, its build pipeline, and the code in this repository, including all assets served from `pull-landing-page.vercel.app`.

**Out of scope:** third-party services (Vercel platform, GitHub), the product application on other domains, social engineering, and volumetric/denial-of-service testing.
